# QX TS: Quotex Semi-Automated & Automated Trading Assistant

A TypeScript & Playwright-based trading assistant and analytics journal built with persistent Chrome CDP session attachment, real-time WebSocket & Redux store telemetry, walk-forward signal validation, and SQLite performance tracking.

---

## Architecture Overview

* **Persistent Chrome Harness (`src/browser/launcher.ts`)**: Attaches via Chrome DevTools Protocol (CDP port `9222`) to a visible Google Chrome instance running with a dedicated profile (`./qx_user_profile`), preserving cookies, 2FA, and Cloudflare clearance.
* **Dual-Layer Stream & Redux Sniffer (`src/stream/wsSniffer.ts`, `src/stream/wsParser.ts`)**: Passively intercepts Socket.IO WebSocket frames and reads Quotex's live React Fiber / Redux store (`chartSettings`, `assets.assetBySymbol`, `deals.openedById`, `global.liveBalance` / `demoBalance`).
* **Multi-Timeframe Candle Aggregator (`src/stream/candleAggregator.ts`)**: Aggregates live ticks and seeds historical candles across supported timeframes (`5s` to `1h`) with strict symbol isolation.
* **Signal & Walk-Forward Calibration Engine (`src/analysis/signalEngine.ts`, `src/analysis/indicators.ts`, `src/analysis/visualChartEngine.ts`)**: Evaluates 3 playbooks (`EMA_PULLBACK_SNIPER`, `MOMENTUM_CHANNEL`, `STREAK_EXHAUSTION_FADE`) across 3 indicator parameter profiles (`FAST`, `STANDARD`, `SMOOTH`) and multi-candle expiry horizons using Wilson lower-bound shrinkage and genuine Out-of-Sample (OOS) validation on closed candles.
* **Trade Journal & Statistical Verdict Engine (`src/journal/database.ts`, `src/journal/tradeWatcher.ts`, `src/analysis/binaryMath.ts`)**: Logs all trades, indicator snapshots, and market regimes to `./data/qx_trading.db` and evaluates statistical edge using Wilson 95% confidence intervals against break-even win rates.

## Quick Start

### 1. Launch Visible Chrome & Bot (Windows)
Double-click `START_QX_BOT.bat` (or run `OPEN_QUOTEX_CHROME.bat` first to open Chrome on port `9222`, then start the bot):

```bash
npm start
```

### 2. First-Time Login
* When Chrome opens to Quotex, sign into your account (Demo or Live) and pass any Cloudflare check.
* Your session is stored in `./qx_user_profile` for future runs.

### 3. Operating Modes
On startup, the interactive CLI prompts for:
1. **Account Selection (`DEMO` vs `LIVE`)**: Automatically verifies and switches the active Quotex account mode.
2. **Operating Mode (`MANUAL` vs `AUTO`)**:
   * **MANUAL**: Passively watches your active chart and issues calibrated Telegram-style signal calls with audio/HUD alerts at candle boundaries.
   * **AUTO**: Manages a multi-tab watchlist of high-payout pairs ($\ge 80\%$), prunes pairs that fail out-of-sample walk-forward validation or suffer 2 consecutive losses, and places trades at candle boundaries with Redux deal confirmation.

## Trade Journal & Performance Analytics

To inspect your historical performance report at any time (or double-click `VIEW_REPORT.bat`):

```bash
npm run journal:report
```

This reports:
* Overall win rate, Live vs. OTC win rates, and exact break-even threshold for your average payout.
* Expected Value (EV) per trade and net PnL.
* Performance breakdown by asset and market regime (`TRENDING_UP`, `TRENDING_DOWN`, `RANGING`, `HIGH_VOLATILITY`).
* **Statistical Edge Verdict**: Uses a 95% Wilson score interval to tell you honestly whether your results represent a statistically proven edge, an inconclusive sample, or a losing strategy.

## Statistical Reality Check
Binary options are a negative-sum fixed-odds bet: at an 85% payout you must win **54.05%** of trades just to break even. OTC prices are generated by the broker rather than an central exchange. Always validate any playbook over hundreds of trades on a **Demo account** (`npm run journal:report`) before risking real capital.
